# Hermes AVO

NVIDIA AVO-style planning engine for autonomous agent orchestration.

## Phase 1: Planning Engine + DeepAgent Wrapper

- **58+7 tests** | **95% coverage**
- Deep planning engine with multi-step decomposition
- DeepAgent wrapper for recursive planning + execution
- MCP tool bridge for agent-to-agent communication

## Quick Start

```bash
# Install dependencies
pnpm install

# Run tests
pnpm test

# Run the planning engine
pnpm dev
```
